# KSENIA ZARETSKAYA PORTFOLIO

Готовый статический сайт: HTML + CSS + JS.

## Картинки
Все изображения лежат в `assets/images/`.
В HTML возле каждого изображения есть комментарий `TODO: ЗДЕСЬ ПОМЕНЯТЬ КАРТИНКУ...`.
Самый простой способ заменить работу — заменить demo-файл и оставить то же имя.

## Тексты
Редактируй `index.html`, `about.html`, `contact.html` и файлы в `projects/`.
Ищи `TODO: ЗДЕСЬ ПОМЕНЯТЬ...`.

## Запуск
Открой `index.html` в браузере. Для разработки удобно использовать VS Code + Live Server.

Демо-проекты концептуальные: NOVA, FORMA, MUSE, AERA, NOIR, KIN, MONO, VANTA.
